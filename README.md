# LapVoice CLI

Spoken lap-by-lap coaching for iRacing, generated by an AI model running **entirely on your own
PC**. No account, no API key, no subscription, and nothing leaves your machine.

After each lap it compares you to your best lap of the session, finds where you lost time, and
tells you through your speakers.

This repository is the free command-line coach. The desktop app - movable overlays, spoken tips
and a track map that learns itself - is a separate, paid product: <https://lapvoice.com>.

## Requirements

- Windows 10 or 11, Python 3.10+
- iRacing
- [Ollama](https://ollama.com/download) for the spoken tips. Optional: without it you still get
  the built-in template tips.

## Install

```
setup.bat        # creates .venv, installs the dependencies, pulls the model
run.bat          # starts the coach
```

Or by hand:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
ollama pull llama3.2:3b
python -m iracing_coach
```

## Options

```
python -m iracing_coach --check          # is everything ready?
python -m iracing_coach --demo           # try it with simulated laps, no iRacing needed
python -m iracing_coach --no-llm         # built-in tips only
python -m iracing_coach --no-voice
python -m iracing_coach --model qwen2.5:7b
```

## Settings

`config.yaml` lists every option, commented out, with its default. Copy it to
`config.local.yaml` and edit that instead: your file overrides `config.yaml` and survives
updates.
